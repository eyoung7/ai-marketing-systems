# AI Marketing Systems

Practical patterns for applying AI to real marketing work.

This repository contains sanitized examples of the workflows, skills, governance practices, and operating models I use when thinking about AI-enabled marketing systems.

My approach starts with the work itself — not the model. I look at:

1. What job is actually being done?
2. Where does judgment matter?
3. What context does the system need?
4. What can safely be automated?
5. Where should a human remain in the loop?
6. How will we evaluate whether the workflow is actually useful?
7. What would prevent this from being responsibly deployed?

## Principles

- Solve a real workflow problem before choosing a tool.
- Treat context as part of the system architecture.
- Separate prototypes from deployable workflows.
- Keep human review where judgment, risk, or brand impact matters.
- Measure usefulness, not just output volume.
- Document failure modes and assumptions.
- Build for adoption, not novelty.

## What's here

A reusable template for specifying a new workflow before building it.
